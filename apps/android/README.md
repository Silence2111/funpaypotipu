# Приложение для Android: Google Play и RuStore

Приложение — это сайт в оболочке Trusted Web Activity: открывается с
иконки, без адресной строки, со своим экраном загрузки. Отдельного кода
нет: приложение показывает тот же сайт и обновляется вместе с ним. Пуши
сайта приходят как уведомления приложения.

Собирается [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) из
`twa-manifest.json` — шаблона с нашими цветами, иконками и пакетом.

## Что нужно

- Сайт на своём домене по HTTPS — с ним сверяется приложение.
- Node 22, JDK 17. Android SDK Bubblewrap скачает сам при первом запуске.
- Аккаунт разработчика Google Play и (или) RuStore.

## Сборка

1. В `twa-manifest.json` заменить `gamemarket.example` на свой домен,
   при желании — `packageId` (после публикации его не сменить).
2. В этой папке: `npx @bubblewrap/cli build`. В первый раз Bubblewrap
   спросит пути к JDK и SDK и создаст ключ подписи `android.keystore`.
   Ключ и пароль хранить вне репозитория: без них приложение в магазине
   не обновить. Если поля шаблона не подойдут вашей версии Bubblewrap —
   `npx @bubblewrap/cli init --manifest https://<домен>/manifest.webmanifest`
   соберёт файл заново по манифесту сайта.
3. Отпечаток ключа:
   `keytool -list -v -keystore android.keystore -alias gamemarket` —
   строка `SHA256:`.
4. На сервере сайта задать `ANDROID_PACKAGE_NAME` (пакет из шага 1) и
   `ANDROID_CERT_SHA256` (отпечаток) и проверить
   `https://<домен>/.well-known/assetlinks.json`. Без этого приложение
   откроет сайт с адресной строкой, как обычную вкладку.

Результат: `app-release-bundle.aab` — для Google Play,
`app-release-signed.apk` — для RuStore и установки напрямую.

## Публикация

- **Google Play.** Загрузить `.aab`. Если включена подпись приложений в
  Google Play, магазин подписывает приложение своим ключом: его отпечаток
  (Play Console → Тестирование и выпуск → Целостность приложения)
  добавить в `ANDROID_CERT_SHA256` через запятую.
- **RuStore.** Загрузить `.apk`. Если магазин подписывает своим ключом —
  так же добавить и его отпечаток.
- Проверка после установки: сайт открылся без адресной строки — связь
  приложения и сайта подтверждена.

## До публикации решить владельцу

- **Правила оплаты магазинов.** Google Play требует свою систему оплаты
  для цифровых товаров внутри приложений, но делает исключения — в том
  числе для платежей между пользователями. Подпадает ли площадка под
  исключение и как это будет у RuStore, решает владелец с юристом до
  публикации — код здесь ничего не обещает.
- **Описание, скриншоты, политика данных** в карточке магазина. Скриншоты
  с телефона — в `apps/web/public/screenshots/`, их же показывает окно
  установки сайта в Chrome.

## iPhone

App Store не принимает сайт в оболочке без собственных функций
приложения. На iPhone сайт ставится через Safari: «Поделиться → На экран
„Домой“», а с iOS 16.4 установленному сайту приходят и пуши.
